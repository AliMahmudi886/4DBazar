# راهنمای استفاده از برند 4D

## Assetهای رسمی پروژه

| کاربرد | فایل | قاعده استفاده |
|---|---|---|
| لوگوی اصلی header و صفحات عریض | `apps/web/public/brand/4d-logo-horizontal.png` | روی زمینه روشن، با نسبت افقی و بدون کشیدگی |
| لوگومارک و آیکن اپ | `apps/web/public/brand/4d-mark.png` | برای favicon، PWA و فضاهای مربعی |
| نسخه قبلی واردشده | `apps/web/public/brand/4d-logo.png` | deprecated؛ در UI جدید استفاده نشود |

## رنگ‌های برند

- Navy: `#052651`
- Teal: `#009688`
- Yellow: `#FFC107`

## قرارداد UI

- لوگوی افقی در header با `object-fit: contain` و عرض responsive نمایش داده می‌شود.
- لوگومارک برای فضای مربعی استفاده می‌شود؛ لوگوی افقی داخل مربع فشرده نمی‌شود.
- نسبت تصویر هیچ asset لوگو نباید با CSS تغییر کند.
- روی زمینه خیلی تیره، این نسخه روشن مناسب است؛ نسخه معکوس باید جداگانه از تیم برند تهیه شود و با حدس رنگی تولید نشود.

## وضعیت

این سند مرجع انتخاب asset برای توسعه وب و اپ موبایل است. هر asset جدید باید نام کاربرد، زمینه مجاز و حداقل اندازه خوانایی داشته باشد.
