# گزارش Development Sprint 92 - Increment 3

تاریخ: ۱۴۰۵/۰۶/۰۱

## هدف

یکپارچه‌کردن تجربه پروفایل، پشتیبانی، رسانه آگهی و کنترل‌های پنل ادمین؛ همراه با انتشار نسخه‌دار و rollback-safe برای cPanel.

## انجام‌شده

- تفاوت «وضعیت حساب» و «اطلاعات حساب» در پروفایل روشن شد؛ اطلاعات کامل‌شده خلاصه می‌شود و تغییر اطلاعات مسیر جدا دارد.
- پشتیبانی به دکمه شناور آیکونی و پنجره popup منتقل شد تا پروفایل خلوت‌تر بماند.
- رسانه آگهی در feed، آگهی‌های کاربر و جزئیات آگهی از API خوانده می‌شود؛ پس از refresh تصویر نباید حذف شود.
- فرمت‌های مجاز تصویر/ویدیو محدود و preview چندرسانه‌ای فرم ثبت اضافه شد.
- خطای ثبت asset رسانه در production دیگر مخفی نمی‌شود و در صورت نبود migration پاسخ 503 قابل‌تشخیص می‌دهد؛ fallback فقط برای تست‌های بدون DB رسانه فعال است.
- پنل ادمین جست‌وجوی کاربر، وضعیت verification، جزئیات آگهی‌دهنده/رسانه و حذف آگهی دارد.
- ساخت release cPanel به staging موقت تغییر کرد تا ZIPهای نسخه‌های قبلی حذف نشوند.

## وضعیت موارد محصول

| مورد | وضعیت |
|---|---|
| تفاوت اطلاعات حساب و وضعیت حساب | انجام‌شده |
| پشتیبانی popup | انجام‌شده در وب؛ smoke روی production باقی است |
| چند عکس و یک ویدیو | API و وب آماده؛ تست واقعی چندفایلی cPanel باقی است |
| جزئیات آگهی‌دهنده در ادمین | انجام‌شده در API و UI |
| جست‌وجوی کاربر در ادمین | انجام‌شده در UI بر مبنای فهرست API |
| حذف آگهی توسط ادمین | انجام‌شده |
| فهرست کامل روستاها | نیازمند منبع محلی معتبر و راستی‌آزمایی |
| composer مستقل ثبت آگهی | هنوز pending؛ preview و اعتبارسنجی بهبود یافته |

- smoke واقعی cPanel برای profile، support، چند عکس، ویدیو و پنل admin.
