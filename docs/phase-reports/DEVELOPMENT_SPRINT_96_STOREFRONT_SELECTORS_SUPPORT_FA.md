## اقدام انتشار

بعد از آپلود release وب/API، API را restart کن. اگر صف غرفه خالی بود، ابتدا migrationهای مقصد را اجرا کن:

```bash
source ~/nodevenv/4d-api/20/bin/activate
cd ~/4d-api
npm run db:migrate
```
