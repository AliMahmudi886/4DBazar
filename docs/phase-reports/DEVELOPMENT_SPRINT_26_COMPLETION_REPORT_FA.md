# Completion Report - Development Sprint 26

## وضعیت

Development Sprint 26 تکمیل شد. هدف این sprint بهتر کردن فضای کاربر بعد از ورود بود: کاربر باید آگهی‌های خودش، وضعیت بررسی، گفتگوها و ادامه چت را بدون حدس زدن پیدا کند.

## انجام‌شده

- کارت «آگهی‌های من» از نمایش صرفا عددی خارج شد و آخرین آگهی‌های کاربر را همراه وضعیت و قیمت نشان می‌دهد.
- جزئیات آگهی‌های خود کاربر از داخل پروفایل باز می‌شود، حتی اگر آگهی هنوز `submitted` باشد و در feed عمومی دیده نشود.
- لیست گفتگوها در پروفایل نقش کاربر را به‌صورت خریدار/فروشنده و زمان آخرین فعالیت نشان می‌دهد.
- اگر برای یک آگهی مکالمه قبلا ساخته شده باشد، drawer جزئیات آگهی به جای شروع تماس دوباره، دکمه «باز کردن چت» نمایش می‌دهد.
- شروع گفتگو برای آگهی منتشرنشده guard شد تا کاربر پیام واضح بگیرد و مکالمه نادرست ساخته نشود.
- استایل workspace list اضافه شد تا پروفایل کمتر خشک و قابل اسکن‌تر باشد.

## Validation

موفق:

- `npm run check`
- `npm run build`
- `npm test`
- `npm run qa:visual`

## نتیجه

فضای «حساب من» دیگر فقط پروفایل و چند شمارنده نیست؛ کاربر حالا می‌تواند از همان‌جا آگهی‌های خودش را دنبال کند، وضعیت انتشار را بفهمد و به گفتگوهای مرتبط برگردد.

## کارهای باقی‌مانده

- افزودن unread count و read state برای گفتگوها
- notification ساده برای پیام جدید
- جایگزینی ذخیره base64 عکس با object storage
- تست کاربری beta با چند حساب واقعی و چند گفتگوی دوطرفه
