# گزارش Development Sprint 92 - Increment 2

تاریخ: ۱۴۰۵/۰۵/۳۰

## هدف

وصل‌کردن قابلیت‌های مدیریتی و پشتیبانی فاز قبل به رابط وب و ساده‌کردن نمایش پروفایل کاربر.

## انجام‌شده

- پنل ادمین اکنون فهرست کاربران را برای نقش `admin` می‌خواند و امکان تأیید وضعیت کاربر دارد.
- پنل ادمین امکان حذف دائمی آگهی را برای نقش `admin` نشان می‌دهد و قبل از حذف تأیید می‌گیرد.
- صف پشتیبانی و پاسخ‌دادن به تیکت‌ها برای نقش moderator به پنل اضافه شد.
- فرم ارسال تیکت پشتیبانی داخل پروفایل کاربر اضافه شد و سابقه پاسخ‌ها نمایش داده می‌شود.
- پروفایل تکمیل‌شده به‌صورت خلاصه نمایش داده می‌شود؛ فرم اطلاعات ضروری و دکمه تغییر اطلاعات جدا شده‌اند.
- build وب، type-check و تست‌های پروژه موفق شدند.

## وضعیت موارد محصول

| مورد | وضعیت |
|---|---|
| ساختار روستاها و جست‌وجوی شهر | انجام API/مدل و جست‌وجوی پایه؛ فهرست روستاها هنوز نیازمند تکمیل و راستی‌آزمایی محلی است |
| پشتیبانی سایت | انجام‌شده در پروفایل و پنل ادمین |
| چند عکس و یک ویدیو | API و وب/موبایل پیاده‌سازی شده؛ نیازمند smoke روی هاست |
| جزئیات آگهی‌دهنده در ادمین | API جزئیات آماده است؛ نمایش کامل creator در UI جزو increment بعدی است |
| حذف آگهی توسط ادمین | انجام‌شده |
| فرم خدمات | پایه و فیلدهای service موجود؛ طراحی کامل سناریوهای تعرفه و فیلتر deferred |
| بهبود ثبت آگهی و پروفایل | پروفایل خلاصه/ویرایش و بخشی از فرم انجام‌شده؛ composer modal هنوز باقی است |
| نشان‌های اعتماد | انجام‌شده و در پروفایل نمایش داده می‌شود |
| دسته‌بندی و فیلتر شبیه دیوار | دسته‌بندی و فیلتر پایه انجام‌شده؛ taxonomy کامل تجاری باقی است |
| دکمه ثبت آگهی در موبایل وب | مسیر و اسکرول اصلاح شده؛ modal مستقل باقی است |
| ادمین کاربران و verification | انجام‌شده در UI و API |
