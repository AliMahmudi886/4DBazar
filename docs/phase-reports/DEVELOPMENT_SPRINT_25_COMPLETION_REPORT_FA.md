# Completion Report - Development Sprint 25

## وضعیت

Development Sprint 25 تکمیل شد. هدف این sprint اصلاح تجربه عمومی، ثبت‌نام/ورود، media آگهی و مرزبندی دقیق‌تر ادمین بود.

## انجام‌شده

- pillهای فنی `API/DB/Auth` از بازار عمومی و کاربر واردنشده حذف شدند.
- statusهای فنی فقط برای moderator واردشده در مسیر admin دیده می‌شوند.
- تجربه ورود به «ثبت‌نام و ورود» تغییر کرد و ساخت خودکار حساب بعد از OTP موفق شفاف شد.
- شماره ایرانی در web و API برای حالت‌های `093...`، `938...`، `989...` و `+989...` normalize می‌شود.
- شماره ادمین از `ADMIN_PHONE_NUMBERS` نقش `moderator` می‌گیرد.
- کپچای پازلی/اسلایدری قبل از ارسال OTP اضافه شد.
- فرم ثبت آگهی عکس می‌گیرد، preview نشان می‌دهد و عکس را در DB MVP ذخیره می‌کند.
- کارت آگهی و drawer جزئیات، عکس آگهی را نمایش می‌دهند.
- عکس‌های معمولی قبل از ذخیره به صورت client-side فشرده می‌شوند.
- ورود با رمز برای کاربران دارای حساب اضافه شد و SMS به ثبت‌نام/فراموشی رمز محدود شد.
- پروفایل اجباری شامل نام، نام خانوادگی، شهر اصلی و رمز عبور اضافه شد.
- ثبت آگهی تا تکمیل احراز هویت سبک پروفایل قفل شد.
- چت داخل برنامه اضافه شد؛ شروع تماس روی آگهی persisted مکالمه می‌سازد.
- drawer چت برای مشاهده و ارسال پیام اضافه شد.
- شمارنده «آگهی‌های من» از endpoint اختصاصی کاربر خوانده می‌شود.
- timeline فنی کنار فرم ثبت آگهی به مسیر انتشار کاربرپسند تبدیل شد.
- migrationهای جدید `0006_listing_media.sql`، `0007_user_profile_security.sql` و `0008_conversations.sql` اضافه و اجرا شدند.
