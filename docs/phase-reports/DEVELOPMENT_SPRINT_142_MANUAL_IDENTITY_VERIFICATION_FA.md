# گزارش Development Sprint 142 — احراز هویت دستی با بررسی مدارک

## خروجی

- مسیر احراز هویت از پشتیبانی جدا شد و کاربر از پروفایل فرم مستقل دریافت می‌کند.
- نوع مدرک، چهار رقم پایانی کد ملی و تصویر/PDF مدرک دریافت می‌شود؛ سقف فایل ۵ مگابایت است.
- مدرک در رسانه عمومی آگهی قرار نمی‌گیرد و فقط از مسیر احراز هویتِ محافظت‌شده برای ادمین قابل مشاهده است.
- پنل ادمین صف درخواست‌های در انتظار، مشاهده مدرک، تأیید و رد با دلیل دارد.
- وضعیت کاربر از آخرین درخواست احراز خوانده می‌شود و پس از تصمیم ادمین با تازه‌سازی پایدار می‌ماند.

## بررسی

- `npm run check` سبز
- `npm run build` سبز
- `npm test` سبز: ۶۳ تست
- `npm run bundle:check` سبز

## ملاحظه انتشار

قبل از استفاده گسترده، سیاست نگهداری/حذف مدارک و رمزنگاری در سطح دیسک یا دیتابیس باید در زیرساخت production قطعی شود. API فعلی دسترسی را محدود و پاسخ مدرک را `no-store` می‌کند.
