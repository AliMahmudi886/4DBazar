# Development Sprint 125 — Admin User Detail

## هدف

تکمیل مرحله بعدی مأموریت Admin/Support/User UX با تمرکز محدود بر مشاهده جزئیات کاربر در پنل ادمین.

## وضعیت قبل

فهرست کاربران فقط یک انتخابگر و یک ردیف خلاصه داشت و وضعیت حساب، تأیید شماره و تاریخ عضویت در کنار هم قابل مشاهده نبود.

## تغییرات

- پنل جزئیات کاربر با داده‌های واقعی endpoint فعلی اضافه شد.
- نام، شماره، وضعیت حساب، وضعیت verification، وضعیت تأیید شماره، تاریخ عضویت و شناسه کاربر نمایش داده می‌شود.
- عملیات واقعی `verified` و `profile_complete` حفظ و واضح‌تر ارائه شد.
- هیچ endpoint یا migration جدیدی اضافه نشد و دسترسی همچنان فقط برای admin است.
