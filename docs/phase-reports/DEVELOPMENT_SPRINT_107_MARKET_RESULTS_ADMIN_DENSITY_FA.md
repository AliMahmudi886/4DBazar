# گزارش تکمیل Development Sprint 107

## هدف

اصلاح discoverability نتایج جست‌وجوی حمل‌ونقل، مدیریت آگهی‌های کاربر و کاهش شلوغی پنل ادمین.

## تغییرات

- نتایج transport از launcher به feed اصلی بازار منتقل شدند و هر نتیجه لینک مستقیم `/listing/{id}` دارد.
- پروفایل برای آگهی‌های کاربر action مستقل ویرایش و حذف دارد؛ ویرایش فرم موجود را با داده‌های آگهی پر می‌کند.
- کاربران ادمین با جست‌وجو و dropdown تک‌کاربره نمایش داده می‌شوند.
- جزئیات آگهی ادمین در dialog ثابت نسبت به viewport با max-height، اسکرول داخلی، Escape و قفل اسکرول صفحه نمایش داده می‌شود.

## اعتبارسنجی

- `npm run check` سبز.
- `npm run build -- --ignore-scripts` سبز.
- تست‌های API و shared سبز هستند.

## موارد باز

- smoke واقعی روی cPanel باید با release هم‌نسخه وب/API انجام شود.
- تست دستگاهی موبایل و برخورد modal با bottom navigation در مقصد باقی است.
