# گزارش Development Sprint 110

## هدف

رفع ناهماهنگی ابعاد رسانه و launcherها و تبدیل صفحه جزئیات آگهی به یک تجربه بصری منسجم و responsive.

## تغییرات

- لینک و تصویر کارت آگهی تمام قاب ثابت رسانه را پر می‌کنند و تصویر با `cover` و مرکز صحیح نمایش داده می‌شود.
- launcherهای ثبت آگهی/خدمت و حمل‌ونقل در دسکتاپ ارتفاع یکسان دارند؛ در موبایل ارتفاع محتوامحور باقی می‌ماند.
- صفحه جزئیات به گالری ۴:۳، thumbnail، شمارنده رسانه، empty state، اطلاعات دسته‌بندی‌شده، توضیحات مستقل و CTAهای پایدار مجهز شد.
- layout در عرض‌های دسکتاپ و موبایل از نظر overflow، نسبت تصویر و دسترسی به actionها بررسی شد.

## اعتبارسنجی

- `npm run check`: موفق
- `npm run build -w @four-d/web`: موفق
- `npm test`: موفق؛ ۵۴ تست
- `npm run bundle:check`: موفق؛ JS کل ۶۳۳ کیلوبایت
- `npm run qa:quality`: موفق؛ Firefox به‌علت runtime محلی قابل اجرا نبود
- کنترل مرورگر: کارت ۲۹۰x۳۹۸ با رسانه ۲۸۹x۱۸۰، launcherهای ۳۵۰x۲۷۰ و صفحه جزئیات بدون overflow در ۳۹۰ و ۱۲۸۰ پیکسل

## موارد باز

- deploy جفت وب/API روی cPanel و Restart App
- smoke بصری بازار و جزئیات روی دامنه production
- smoke حذف، ویرایش ۲۴ساعته و رسانه در مقصد
