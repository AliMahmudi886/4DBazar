# گزارش Development Sprint 104: جست‌وجوی حمل‌ونقل و تست بار محلی

تاریخ: ۱۴۰۵/۰۶/۰۲

## خروجی

- endpoint `GET /api/v1/transport/search` اضافه شد.
- فیلترهای عبارت، مبدأ، مقصد، تاریخ، نوع سفر و limit محدودشده پشتیبانی می‌شوند.
- فقط محتوای `approved` و سفرهای `active` در جست‌وجوی عمومی برمی‌گردند.
- حروف عربی و اعداد فارسی پیش از جست‌وجو نرمال می‌شوند.
- `LOAD_TEST_MODE=true` فقط برای localhost و خارج از production، rate limit سراسری را برای تست ظرفیت محلی کنار می‌گذارد.

## علت خطای تست قبلی

در اجرای قبلی ۵۴۱۹ درخواست ثبت شد؛ ۴۶۹۹ مورد پاسخ 429 ناشی از rate limit بودند و خطای واقعی سرور صفر بود. این رفتار حفاظتی برای اجرای عادی درست است، اما ظرفیت خام API را نشان نمی‌دهد.
