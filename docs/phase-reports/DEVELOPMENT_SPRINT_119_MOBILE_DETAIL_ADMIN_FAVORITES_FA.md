# گزارش Sprint 119 — جزئیات آگهی، ذخیره و پنل مدیریت موبایل

## دامنه

این increment فقط روی تجربه موبایل در جزئیات آگهی، ذخیره آگهی و نمایش پنل مدیریت انجام شد.

## تغییرات

- برچسب فیلدهای داینامیک در جزئیات آگهی و پنل مدیریت فارسی و خوانا شد؛ مقادیر رایج مانند `apartment` و `used` نیز ترجمه می‌شوند.
- متن دکمه تماس از «شروع گفتگوی امن» به «شروع گفتگو» تغییر کرد.
- پنل مدیریت از حالت نمادین خارج شد و موارد واقعی API را با جزئیات آگهی، ویژگی‌ها و عملیات مرتبط نمایش می‌دهد.
- ذخیره آگهی در کارت‌های بازار بازخورد بارگذاری دارد، با لمس کارت تداخل نمی‌کند و خطای واقعی API را به کاربر نشان می‌دهد.
- فیلتر حمل‌ونقل در موبایل به‌صورت جمع‌شونده نمایش داده می‌شود تا صفحه را اشغال نکند.

## محدودیت‌های تست

- تماس با آگهی متعلق به همان کاربر عمداً توسط API رد می‌شود؛ برای تست تماس موفق باید آگهی متعلق به کاربر دیگری باشد.
- عملیات پنل مدیریت نیازمند حساب دارای نقش مدیر/ناظر است.
- شمارنده بازدیدِ صاحب آگهی برای مشاهده‌های خودش عمداً افزایش نمی‌یابد.
