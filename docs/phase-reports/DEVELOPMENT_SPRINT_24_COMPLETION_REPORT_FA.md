# Completion Report - Development Sprint 24

## وضعیت

Development Sprint 24 تکمیل شد. هدف این sprint نهایی‌کردن تجربه beta برای ورود واقعی، کاربر عادی و ادمین بود.

## انجام‌شده

- auto-login توسعه‌ای از boot وب حذف شد.
- ورود واقعی OTP در UI اضافه شد: شماره موبایل، ارسال کد و verify کد.
- دکمه «ورود سریع» با مسیر «ورود» واقعی جایگزین شد.
- workspace «حساب من» برای پروفایل، نقش‌ها، آگهی‌های من و مسیر ثبت آگهی اضافه شد.
- تب ادمین فقط برای کاربر دارای نقش `moderator` نمایش داده می‌شود.
- داده‌های queue ادمین فقط برای نشست moderator fetch می‌شوند.
- ثبت آگهی، تماس و گزارش بدون ورود، کاربر را به ورود هدایت می‌کند.
- UI صفحه ورود/پروفایل responsive و نرم‌تر شد.
